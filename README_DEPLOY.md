# GEOG 524 Monte Carlo — Streamlit Community Cloud

1. Create a GitHub repository containing `app.py`, `mc_analysis.py`, `requirements.txt` and `data/`.
2. Keep only public, non-sensitive teaching data in the repository.
3. Sign in to Streamlit Community Cloud using GitHub.
4. Select **Create app**, choose the repository and branch, and set `app.py` as the entry point.
5. Deploy and test the resulting public URL in a private browser session.
6. Students use the hosted app; they do not install Python or run local servers.

Commit changes to the selected branch to update the deployed app. Check deployment logs if dependency installation or startup fails.

This is a teaching demonstration, not a guaranteed production service. Free-tier resource limits and service terms can change. Keep simulations and datasets modest. No local tunnelling, SSH forwarding or localhost exposure is required.
